# 💙 Donate Bangladesh  

**Donate Bangladesh** is a simple and responsive donation platform built with **Tailwind CSS, JavaScript, and DaisyUI**. It allows users to contribute towards various relief efforts, including flood relief and medical aid.  

## 🔗 Live Project  
[View Here](https://souravdn-p.github.io/SD_ASSIGNMENT_05/)  

## 🛠 Technologies  
- **HTML** – Structuring the web content  
- **Tailwind CSS & DaisyUI** – Styling and UI components  
- **JavaScript** – Handling interactivity  

## 🚀 Features  
- **Donation Categories** – Supports different causes like flood relief & medical aid  
- **Live Donation Amount Display** – Shows real-time updates on donations  
- **User-Friendly UI** – Simple, clean, and easy-to-use interface  
- **Responsive Design** – Works on mobile, tablet, and desktop
